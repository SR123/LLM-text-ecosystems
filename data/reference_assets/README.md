# Reference Assets

This folder contains paper-facing copies of figures and tables so the GitHub upload can act as a direct reference companion to the manuscript.

## Contents

- `main_paper_figures/`: copies of the figures used by the Nature manuscript
- `appendix_figures/`: copies of all appendix image files, including `generated/`
- `appendix_tables/`: copies of appendix table sources
- `source_plots/`: paper-support plot exports from the theorem-1 and theorem-2 experiment folders

The canonical experiment outputs remain under `../outputs/`.
These copies exist to make the upload easier to browse and to keep paper-facing artefacts together in one place.
