# Theorem 1 vocabulary reduction plots

This folder contains the appendix-facing plots for vocabulary reduction across Arthur Conan Doyle, Jane Austen, and Charles Darwin.

Included files:

- `figure_appx_theorem1_vocab_retention_multi_corpus.*`: the generated appendix figure used in the appendix.
- `multi_corpus_fixed_vocab_retention.*`: source plot of vocabulary retention across generations.
- `multi_corpus_fixed_vocab_size.*`: source plot of vocabulary size across generations.
- `figure_appx_theorem1_active_vocab_threshold_multi_corpus.*`: related thresholded active-vocabulary plot from the same appendix section.
